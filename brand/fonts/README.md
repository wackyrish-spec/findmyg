# Fonts

Barlow Condensed (600, 700, 800), Manrope (500, 700, 800) and JetBrains Mono (600), downloaded from Google Fonts on 6 Nov 2026. All are under the SIL Open Font License 1.1 (https://openfontlicense.org), which allows bundling and embedding.

They live in the repo so print files and the build-time Open Graph images don't need network access. The website itself still loads them from Google Fonts.
